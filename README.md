# Racing Manager

Racing Manager Grundspiel

Ziel

Erstelle ein vollständig spielbares Browser-Racing-Manager-Spiel.

Der Spieler gründet ein eigenes Motorsport-Team und entwickelt es von einem kleinen Anfängerteam zu einem konkurrenzfähigen Rennstall.

Der Fokus dieser ersten Version liegt auf:

Forschung

Rennen
